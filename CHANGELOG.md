# Changelog

All notable protocol and reference-kit changes are documented here.

The wire protocol follows explicit versioning. Changes to implementation packages that do not alter the wire format may keep the same protocol version.

## 1.0.0 — initial reference

- signed portable collection envelope;
- WIKICARD-C14N-JSON-1 canonicalization;
- Ed25519 issuer signatures;
- Wikidata-first canonical card identity;
- issuer discovery document;
- explicit issuer/client trust policy;
- WIKICARD-AUTH-CODE-1 authorization-code + PKCE flow;
- fresh live collection retrieval;
- destination-service and destination-account binding;
- one-time replay-resistant state/code/token model;
- TypeScript core and server reference packages;
- Fastify and framework-neutral browser examples;
- JSON Schema and OpenAPI specifications;
- VitePress developer portal;
- Docker documentation deployment example.
