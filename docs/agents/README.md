# Coding Agent Guides

Use these files when an AI/code agent integrates the protocol into an existing codebase.

Start with root `AGENTS.md`.

Then:

1. `framework-selection.md` — detect the host framework.
2. `node-agent-guide.md` or `python-agent-guide.md`.
3. the local `AGENT.md` inside the matching framework example.
4. `integration-task-template.md` for a reusable task brief.

The guides intentionally instruct agents to preserve the host application's authentication, framework and database architecture instead of creating parallel infrastructure.
